# 🌙 Lunaria — A Little Garden of Light

### A peaceful virtual garden where little moments bloom into magic.

Lunaria is an interactive virtual flower garden built with HTML, Tailwind CSS, CSS, and JavaScript. It features glowing flowers, animated fireflies, and a magical day-night transition, creating a calm and immersive web experience.

**Live Demo:** [Lunaria — A Little Garden of Light](https://suprio-dev.github.io/Lunaria-/)

---

## ✨ Features

- Interactive glowing flowers
- Dynamic day and night mode
- Animated stars and shooting star
- Floating fireflies with smooth animations
- About overlay with interaction guide
- Responsive design for different screen sizes
- Glassmorphism UI with smooth transitions

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structuring the application |
| Tailwind CSS | Styling, layout, and responsive design |
| CSS3 | Animations, transitions, and visual effects |
| JavaScript | Interactive behavior and event handling |
| DOM API | Selecting and updating UI elements |

---

## 🔄 How It Works

```text
Open Lunaria
    ↓
Explore the Virtual Garden
    ↓
Switch Between Day and Night
    ↓
Tap on Flowers
    ↓
Activate Their Glow Effects
    ↓
Enjoy the Magical Garden Experience
```

Lunaria uses JavaScript to handle user interactions, while CSS animations bring the flowers, stars, and fireflies to life. Tailwind CSS helps create a responsive and elegant interface.
